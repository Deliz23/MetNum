Fundamentos de Convergencia

Matrices de Iteración T y Radio Espectral ρ(T)

Un método iterativo no resuelve el sistema de golpe: parte de una estimación y la mejora paso a paso. Para usarlo con criterio hay que responder tres preguntas antes de empezar.

¿Converge?
Depende de la matriz de iteración T: converge para cualquier inicio si y solo si ρ(T) < 1.
¿Con qué rapidez?
El error se multiplica por ρ(T) en cada paso. Cuanto más cerca de 0, menos iteraciones.
¿Cuándo detenerse?
Se vigila el residuo y el cambio relativo entre iteraciones, pero ninguno de los dos mide el error por sí solo.

Jacobi

Calcula cada componente solo con los valores de la iteración anterior. Todas las componentes son independientes entre sí.

Gauss–Seidel

Usa de inmediato los valores recién calculados. Suele converger más rápido, pero las componentes dependen unas de otras.

SOR

Mezcla el valor anterior con el de Gauss–Seidel mediante un factor de relajación ω. Con un ω bien elegido acelera mucho la convergencia.

Criterios de convergencia

Los tres métodos son de la forma x(k+1) = T x(k) + c, con A = D + L + U.

Condiciones de convergencia
Condición Qué garantiza
ρ(T) < 1Necesaria y suficiente: converge para cualquier inicio.
‖T‖ < 1 en alguna normaSuficiente. Es la forma práctica de comprobarlo sin calcular valores propios.
Dominancia diagonal estrictaJacobi y Gauss–Seidel convergen. Suficiente, no necesaria.
A simétrica definida positivaGauss–Seidel converge y SOR converge para todo 0 < ω < 2 (Ostrowski–Reich).
0 < ω < 2Condición necesaria de SOR (Kahan): ρ(Tω) ≥ |ω − 1|.

Rapidez y criterios de paro

Como el error cae como ρk, se puede predecir cuántas iteraciones harán falta y compararlo con lo que se observa.

Caso Práctico en Ingeniería

Difusión de Influencia y Ranking en Redes Distribuidas

En redes de servidores, sistemas de reputación (PageRank) y mallados térmicos discretos mediante diferencias finitas, cada nodo calcula su estado a partir de las interacciones continuas con sus vecinos.

Significado de las Ecuaciones

El puntaje o potencial xi de cada nodo es una combinación lineal de una fuente base (lado derecho b) más la influencia transmitida por los demás nodos de la topología.

Arquitectura de Software y Paso Iterativo

Para resolver sistemas dispersos de gran dimensión donde almacenar A⁻¹ es prohibitivo en memoria, los tres algoritmos comparten una interfaz común: 

metodo.paso(A, b, x, omega) -> x_nuevo

iterar(metodo, A, b, x0, {omega, tol, maxIter})
  -> { x, iteraciones, historial, converge }
¿Por qué SOR? Con el factor de relajación óptimo ω_opt, SOR reduce drásticamente el número de pasos requeridos frente a Gauss-Seidel estándar.

Condiciones de Parada

El algoritmo detiene su ejecución cuando el cambio relativo entre iteraciones sucesivas o el residuo relativo de la ecuación cae por debajo de la tolerancia estipulada:

$$\frac{\|x^{(k+1)} - x^{(k)}\|_\infty}{\|x^{(k+1)}\|_\infty} < \text{tol}, \quad \frac{\|b - Ax^{(k+1)}\|_\infty}{\|b\|_\infty} < \text{tol}$$

Si ρ(T) ≥ 1, el método diverge geométricamente y el simulador alertará de inestabilidad espectral.
